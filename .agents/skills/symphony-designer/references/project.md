# Symphony design contract

Apply with [Symphony Designer](../SKILL.md), the pinned shared Designer and the current [repository rules](../../../../AGENTS.md). This contract specializes the foundations; adopting the role does not authorize a redesign, private-source publication or product-scope expansion.

## Product-specific composition and parity

Use [inspect-reference-ui](../../inspect-reference-ui/SKILL.md) as this role's local comparison module. The exact private upstream application remains the visible-behavior/composition baseline. Resolve its read-only checkout only through `SYMPHONY_REFERENCE_ROOT`, never write its value or repository identity into tracked files, and compare the exact corresponding source. Record material Adopt, Adapt or Differ decisions in the [frontend parity handbook](../../../../docs/architecture/frontend-reference/README.md). A screenshot alone is insufficient evidence.

Inspect Symphony's real `ShellView`, [ShellConfig](../../../../apps/renderer/src/configuration/ShellConfig.ts), the affected View/Presenter and their exact reference counterpart. Keep the existing navigation, window boundaries, settings interaction and provider-neutral product data. Loading/error/empty/retry and unavailable native/provider states remain honest. Existing handmade surfaces are findings to assess, not permission to copy controls.

Keep three-file Views and state/commands in their presenters. Tailwind arranges layout only. Public Mosaik inputs, slots, typography and the shared theme express appearance; View styles never override Mosaik parts or internal custom properties. Preserve the sole documented shell exception: layout-only App header/navigation geometry in the App template where no public input exists, recorded as Adapt, with no visual tokens. Follow the [frontend contract](../../symphony-architect/references/frontend.md) and [renderer instructions](../../../../.github/instructions/renderer-architecture.instructions.md).

Every visible element must support a user decision/action, problem resolution or necessary task context. Do not decorate the workspace with architecture, storage/security claims, generic health indicators, duplicate rail/page information or filler badges. Preserve keyboard/focus behavior and stable `test-id` acceptance surfaces.

## Catalog transport

The canonical [.vscode/mcp.json](../../../../.vscode/mcp.json) owns one `mosaik` stdio connection and its generated client projections. It launches the preinstalled `@pixel-brewery/mosaik-mcp@0.1.203` package through `yarn exec mosaik-mcp` from the repository root. This resolves the installed workspace bin without a runtime download. Report the package snapshot/version actually consulted and compare returned APIs with the installed component baseline. Authenticated cloud Studio operations are not available through this local server. Never fall back silently to an online catalog or service. Apply the full mandatory consumer workflow and failure boundary from shared [project integration](../../designer/references/project-integration.md) through this configured local transport.

## Verification and environment

For actual UI work, run the shared Designer checker on the complete affected template/style owner, the owning Nx lint target, `yarn design:md-check` and focused behavioral checks through the configured Yarn/Nx owners. Re-audit every affected route against the exact private reference and verify the flow, applicable widths, keyboard and supported appearances in the actual Electron application. A browser-only preview does not verify Electron boundaries. The [testing](../../symphony-architect/references/testing.md), [E2E](../../symphony-architect/references/e2e.md) and [environment](../../symphony-architect/references/environment.md) contracts own serial execution, isolated temporary state, real-process fixtures and cleanup.

Guidance-only changes require metadata/link/inheritance, generator regressions, synchronization, archive and documentation checks. They do not establish a product runtime. `yarn verify`, `yarn e2e` and `yarn forge:package` remain separate repository checks; invoke Definition of Done only when explicitly requested.
