# Symphony Designer

Read [Designer](../designer/SKILL.md), its [project integration](../designer/references/project-integration.md) and [the local design contract](references/project.md) first. Explicitly compose the shared mandatory consumer workflow with this project's existing theme, product constraints and verification owners. `metadata.inherits` records the relationship; these reads load it.

Apply this local role to every UI question, new idea and design implementation or review. Keep questions and reviews read-only unless implementation is requested. The local contract owns the project's mutation of the shared foundation; do not replace it with default theme choices. Reuse the shared catalog, component/compliance and failure procedure without maintaining another copy. Engineering ownership remains with [Symphony Architect](../symphony-architect/SKILL.md).
