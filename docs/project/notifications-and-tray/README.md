# Mitteilungszentrale und Menüleistenpanel

Die Mitteilungszentrale sammelt, was an Einrichtung und System Aufmerksamkeit braucht, und hält die Hinweise des Tages fest, die Symphony als kurze Einblendungen zeigt. Das Menüleistenpanel (das Symphony-Symbol in der macOS-Menüleiste) zeigt die laufende Arbeit, freie Ausführungsplätze und was auf dich wartet, ohne dass du das Hauptfenster öffnen musst.

## Mitteilungszentrale

### Öffnen und schließen

| Aktion                                                            | Ergebnis                                                                                                |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Klick auf die Glocke rechts in der Statusleiste des Hauptfensters | Öffnet die Mitteilungszentrale nach oben über dem aktuellen Bildschirm; ein zweiter Klick schließt sie. |
| **esc** oder ein Klick außerhalb                                  | Schließt die Mitteilungszentrale.                                                                       |
| **Notifications** im Menüleistenpanel                             | Holt das Hauptfenster nach vorn, wechselt auf **Overview** und öffnet die Mitteilungszentrale.          |

Die Glocke trägt die Zahl der Punkte, die Aufmerksamkeit brauchen. Solange darunter etwas Ungelesenes ist, ist die Zahl rot; danach grau. Ohne offenen Punkt trägt die Glocke keine Zahl.

### Inhalt

- Kopf: **Notifications**, darunter die Zahl der offenen Punkte und woher sie stammen (zum Beispiel `2 need attention · FLAMOX365 and this Mac`), rechts **Mark all as read**.
- **Needs attention**: ein Eintrag je Problem mit Symbol, Titel, Ort als Pfad (zum Beispiel `System › Developer tools`), der Folge oder dem nötigen Kontext und den Schaltflächen, die das Problem beheben. Ungelesene Einträge tragen einen blauen Punkt.
- **Earlier today**: die Hinweise, die Symphony heute in diesem Fenster als Einblendung gezeigt hat, neueste zuerst, mit Uhrzeit. Ein Hinweis, der erschien, während das Fenster nicht im Vordergrund war, gilt als ungelesen.
- Fuß: `Work-item decisions stay in the Inbox.` und **Clear read**.
- Ohne Problem und ohne Hinweis steht dort `Nothing needs your attention`.

Entscheidungen zu Work Items erscheinen nicht hier, sondern in der **Inbox**.

### Welche Probleme erscheinen

| Problem                                                                                                      | Ort                                | Behebung                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------ | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Git fehlt; die GitHub CLI fehlt bei einer GitHub-Verbindung; eine AI-CLI fehlt, auf der ein AI-Konto läuft   | `System › Developer tools`         | **Install with Homebrew** nach derselben Rückfrage wie in den Einstellungen; ohne Homebrew **Open Developer tools**.                                        |
| Ein Codex- oder Claude-Code-Konto ist nicht angemeldet (die CLI ist vorhanden)                               | `<Workspace> › Connected services` | **Sign in** öffnet die Einstellungen beim Workspace unter **Connected services**, wo die Anmeldung läuft.                                                   |
| Ein aktiviertes Repository ist nicht lokal vorbereitet                                                       | `<Workspace> › Repositories`       | **Prepare locally** bereitet das Repository wie in den Einstellungen vor. Bei eingeschaltetem automatischen Arbeiten steht dabei, dass diese Arbeit wartet. |
| Ein Telefon bittet um Kopplung                                                                               | `Mobile access`                    | **Reject** oder **Approve**; der Prüfcode steht im Eintrag.                                                                                                 |
| Verwalteter Speicher nahe oder an seiner Grenze, wenig freier Platz auf dem Mac, schreibende Arbeit gesperrt | `System › Storage`                 | **Review storage** öffnet **System** in den Einstellungen.                                                                                                  |
| Ein Workspace nahe oder an seiner Speichergrenze                                                             | `<Workspace> › Administration`     | **Review storage** öffnet den Workspace unter **Administration**.                                                                                           |

Ein Problem verschwindet, sobald es behoben ist. Beim Ausführen einer Behebung schließt sich die Mitteilungszentrale; die Bestätigung oder die Einstellungen übernehmen.

### Gelesen und aufgeräumt

- **Mark all as read** entfernt die blauen Punkte von Problemen und Hinweisen. Probleme bleiben in **Needs attention**, bis sie behoben sind.
- **Clear read** entfernt die gelesenen Hinweise aus **Earlier today**.
- Hinweise bleiben nur bis zum Ende des Tages und nur, solange Symphony läuft. Jedes Fenster führt seine eigenen Hinweise.

## Menüleistenpanel (macOS)

Ein Klick auf das Symphony-Symbol in der Menüleiste öffnet das Panel. Es ist 328 Pixel breit, wächst mit seinem Inhalt bis zur Höhe von 760 Pixeln und folgt dem Erscheinungsbild der Anwendung (hell, dunkel oder System).

| Bereich             | Inhalt                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kopf                | Symphony-Symbol, `Symphony`, Statuszeile (`2 running · <Workspace>`, `Nothing running · <Workspace>` oder `Latest run failed · <Workspace>`), Schaltflächen **Open Symphony** und **Settings**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `Agents \| Actions` | Dieselbe Umschaltung wie im Laufpanel der Seitenleiste, mit der Zahl laufender Agents beziehungsweise laufender und wartender Actions-Läufe. **Agents** zeigt jeden Agent des aktiven Workspace mit laufender Arbeit oder einem Ergebnis von heute: Figur, Name, Tätigkeit mit Work Item, Laufanzeige oder Statussymbol und **Pause**/**Resume**, wo die Ausführung das erlaubt. **Actions** zeigt laufende und wartende Läufe, danach die letzten beendeten (höchstens vier), jeweils mit Quelle, Zustand, Dauer, Revision und **Open**, und endet mit **All runs in Symphony**. Leer: `No agent is working` beziehungsweise `No action is running` mit `Runs appear here as soon as one starts.` |
| `Execution slots`   | Ein Segment je Ausführungsplatz, belegte gefüllt, daneben `{belegt} of {gesamt} in use`. Wartet ein Schritt auf einen freien Platz, steht das darunter; sind alle Plätze frei, `3 slots are free.`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `Needs you`         | **Inbox** mit der Zahl der Entscheidungen und der ersten Entscheidung; **Notifications** mit der Zahl der offenen Punkte der Mitteilungszentrale und dem ersten Punkt. Beide öffnen das Hauptfenster an dieser Stelle. Ohne offene Punkte entfällt der Bereich.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `Autonomous work`   | Schalter für autonomes Arbeiten und der nächste Zyklus (`Next cycle in 6m`) beziehungsweise `No new autonomous tasks will start.`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Update              | `Update available` mit **Download**, während des Ladens der Fortschritt, `Update ready` mit **Restart to update**; sonst **Check for updates**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Befehle             | **Open Symphony** ⌘O, **New work item…** ⌘N (Hauptfenster mit dem Anlegen eines Work Items), **Settings…** ⌘, (Einstellungsfenster), **Quit Symphony** ⌘Q. Die Kürzel funktionieren im geöffneten Panel.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

Das Symbol in der Menüleiste zeigt weiterhin drei Zustände mit Tooltip: Ruhe (`Symphony`), laufende Arbeit (`Symphony — Run in progress`) und fehlgeschlagener letzter Lauf (`Symphony — Latest run failed`). Schlägt das Laden der Actions fehl, zeigt **Actions** `Actions unavailable` mit dem Grund.
