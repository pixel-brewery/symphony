# Symphony – Produkthandbuch

Das Produkthandbuch beschreibt Symphony aus Sicht der Menschen, die die Anwendung nutzen oder bei ihrer Nutzung unterstützen. Jede Funktionsseite nennt Voraussetzungen, mögliche Aktionen, automatische Folgen und den Umgang mit Fehlern.

## Dokumentierte Funktionen

| Funktion                                                | Inhalt                                                                                                                         |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| [Symphony aktualisieren](application-updates/README.md) | Neue Versionen erkennen, Stable oder Canary wählen und den Installer manuell herunterladen und installieren.                   |
| [Entwicklerwerkzeuge](developer-tools/README.md)        | Lokale CLIs prüfen, fehlende Werkzeuge ausdrücklich installieren und Werkzeugverfügbarkeit von der AI-Anmeldung unterscheiden. |

## Zur Dokumentation beitragen

Die [Dokumentationsgrundsätze](documentation-principles.md) legen fest, welche Aussagen in dieses Handbuch gehören und wie sie überprüft werden. Technische Umsetzung und Architekturentscheidungen stehen im [technischen Handbuch](../architecture/README.md).
