# Appearance

Unter **Appearance** in den [Einstellungen](../window-and-navigation/settings.md) legst du fest, wie Symphony aussieht und ob die optionale **Arcade** in der Navigation erscheint. Die Werkzeugleiste beschreibt den Bereich mit `Choose how Symphony looks.`

## Farbschema

Die Gruppe **Color theme** enthält **Theme** mit den Segmenten **Light**, **Dark** und **System**.

| Auswahl    | Wirkung                                                                                                         |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| **Light**  | Symphony erscheint immer hell. Das ist die Vorgabe einer neuen Installation.                                    |
| **Dark**   | Symphony erscheint immer dunkel.                                                                                |
| **System** | Symphony folgt der Einstellung von macOS und wechselt sofort mit, wenn macOS zwischen hell und dunkel wechselt. |

Die Wahl gilt sofort im ganzen Hauptfenster, die geöffneten Einstellungen eingeschlossen, ohne dass etwas neu geladen wird, und bleibt über einen Neustart erhalten. Die nativen Fensterhintergründe und unter Windows und Linux die Farben der Fensterbedienelemente folgen dagegen der Hell-dunkel-Einstellung des Betriebssystems. Schlägt das Speichern fehl, meldet Symphony `Unable to save settings.` und zeigt wieder das bisherige Farbschema. Das Farbschema lässt sich auch direkt in einem Treffer von **Search settings** ändern, etwa nach der Suche `dark`.

## Arcade einblenden

Die Gruppe **Navigation** enthält **Show Arcade** (`Add all 8 bundled games to the main navigation.`; die Zahl folgt dem Spielekatalog). Der Schalter ist zunächst aus.

- Eingeschaltet erscheint **Arcade** in der Gruppe **More** der Seitenleiste des Hauptfensters (siehe [Hauptfenster und Navigation](../window-and-navigation/README.md)); ausgeschaltet verschwindet der Eintrag wieder. Das Hauptfenster übernimmt die Änderung sofort.
- Solange **Show Arcade** eingeschaltet ist, zeigt die Gruppe zusätzlich **God mode** mit der Tastenfolge ↑ ↑ ↓ ↓ ← → ← → B A. Jede richtig gedrückte Taste wird markiert; zwei Sekunden ohne Taste setzen den Fortschritt zurück. Ist die Folge vollständig, meldet Symphony `God mode activated`, und die Zeile sagt `God mode is active for this session.` Was der Modus in den Spielen bewirkt, beschreibt [Arcade](../arcade/README.md).

**Show Arcade** lässt sich ebenfalls direkt in einem Suchtreffer umlegen. Schlägt das Speichern fehl, zeigt der Schalter wieder den bisherigen Zustand.
