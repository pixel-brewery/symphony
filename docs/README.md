# Symphony-Dokumentation

Die Dokumentation bietet zwei ergänzende Einstiege: Das Produkthandbuch erklärt die Nutzung und sichtbaren Regeln. Das technische Handbuch beschreibt die Umsetzung und ihre verbindlichen Verträge.

| Einstieg                                       | Für welche Fragen?                                                                       |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [Produkthandbuch](project/README.md)           | Was kann Symphony, welche Voraussetzungen gelten und wie wird eine Funktion verwendet?   |
| [Technisches Handbuch](architecture/README.md) | Welche Verantwortlichkeiten, Abläufe, Verträge und Fehlerregeln bestimmen eine Funktion? |
| [Architekturentscheidungen](adr/README.md)     | Welche grundlegenden Entscheidungen sind dokumentiert und wodurch sind sie begründet?    |

Die Funktionsbeschreibungen unterscheiden vorhandenes Verhalten von Voraussetzungen einer noch ausstehenden Bereitstellung. Planungs- und Arbeitsunterlagen sind keine Bestätigung einer bereits verfügbaren Funktion.
