# Solar System planet maps

Creator: Solar System Scope / INOVE.

Source: https://www.solarsystemscope.com/textures/

License: Creative Commons Attribution 4.0 International (CC BY 4.0),
https://creativecommons.org/licenses/by/4.0/

The original 2K Mercury, Venus Atmosphere, Earth Day Map, Mars, Jupiter, Saturn,
Saturn Ring, Uranus and Neptune files are included without modification. They are
mapped onto Symphony's 3D meshes. Planet sizes are intentionally comparable for
navigation; this work landscape is not an astronomical scale model.

The transparent planet portraits in `previews/` are Symphony renders of those
maps and meshes, including Saturn's rings. They are derived images covered by
the same CC BY 4.0 attribution. `previews/sun.png` renders Symphony's procedural
Sun shader and contains no Solar System Scope map. Regenerate all nine portraits
from the actual Orbit renderer with `yarn node tools/render-orbit-previews.mjs`.

These assets are separate from Symphony's source-code license. No endorsement
by Solar System Scope or INOVE is implied.
